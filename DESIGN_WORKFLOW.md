# Design review and exports

Keep the underwater visual direction throughout every section. Use a continuous water-color gradient, soft underwater light, and subtle differences in depth. Preserve readable text, keyboard controls, and reduced-motion behavior.

After every design revision:

1. Inspect desktop at 1920×1080 and mobile at 390×844; check narrow mobile overflow too.
2. Capture the complete page at both widths with `?capture=1` so motion is frozen and images load eagerly.
3. Save PNGs to a new versioned folder under `../design-exports/`; retain earlier versions.
4. Provide both full-page PNGs to the user for importing into Figma. Also provide the 1920×1080 cover image when useful.
5. Verify actual image dimensions. Full-page height is determined by content, not limited to 1080px.
6. Save approved-scope HTML updates to the existing `tpwls4470/PORTPOLIO` repository and verify Pages publication.

Do not present placeholder apps, tools, profile information, or sample redesigns as verified work history. Real project material is still pending.
