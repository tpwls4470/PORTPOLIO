# PORTPOLIO

물속을 천천히 구경하는 느낌의 개인 포트폴리오 HTML 프로토타입입니다.

**콘셉트:** 작은 물방울이 모여 큰 물을 이루듯, 매일의 시도가 쌓여 나의 경험을 만듭니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

로컬 서버로 확인하려면 Node.js 환경에서 `node server.mjs` 실행 후 http://127.0.0.1:4173 에 접속하세요.

## 구성

- 물속 표지: 워터글래스 제목, 작업물을 담은 물방울, 일시정지 기능
- 꾸준한 실험: 매일 콘텐츠 제작과 개별 영상 조회수 사례
- 소개: 자기소개, 활동, 도구
- 활동 기록: 임시 작업 이미지와 소개
- 앱 프로젝트: 상세 대화상자와 기획 과정
- 웹 디자인: 비포·애프터와 개선 방향
- 연락: 실제 이메일 등록 전에는 준비 중 안내 표시

## 실제 정보로 교체할 부분

- `index.html`: YOUR NAME, 프로필, 활동, 사용 도구, 프로젝트 메타데이터
- `app.js`: `profile.email`, 프로젝트별 상세 설명 (`stories`)
- `assets/`: 실제 프로젝트 화면과 프로필 사진

앱과 웹 프로젝트는 구조를 보여주는 **가상 예시**이며, 실제 제작 이력이나 검증된 성과를 의미하지 않습니다. 약 100회와 27만 회는 사용자가 제공한 개별 영상 조회수이며, 전체 평균이나 동일 영상의 시계열 수치가 아닙니다. 실제 변경 사례, 집계 날짜, 플랫폼과 증빙 이미지는 보완 예정입니다.

## 접근성

본문 16px, 주요 조작 영역 48px 이상, 키보드 접근과 포커스 표시, 본문 바로가기, 모달 닫기 및 포커스 복귀를 제공합니다. 물방울은 마우스·키보드 선택 시 멈추며 전체 일시정지 버튼과 시스템 움직임 줄이기 설정을 지원합니다. 최종 이미지와 문구를 교체한 후 대비와 읽기 순서를 다시 점검하세요.

## 이미지와 글꼴

`assets/underwater.png`는 이 프로젝트를 위해 AI로 생성한 배경입니다. 프롬프트: ‘수면 아래 시점, 밝은 물빛, 잔잔한 수면과 굴절된 햇빛, 중앙에 여백, 텍스트·물방울·UI 없음’. 다른 SVG는 임시 프로젝트 화면을 표현한 자체 제작 이미지입니다. 외부 폰트는 Google Fonts의 Fredoka와 jsDelivr의 Pretendard를 사용하며, 연결되지 않아도 시스템 글꼴로 표시됩니다.

## GitHub Pages

저장소 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로 설정하면 정적 사이트로 게시할 수 있습니다. 실제 게시 여부는 GitHub 설정에 따라 결정됩니다.
