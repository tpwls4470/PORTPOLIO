# PORTPOLIO

물속을 천천히 구경하는 느낌의 개인 포트폴리오 HTML 프로토타입입니다.

**콘셉트:** 작은 물방울이 모여 큰 물을 이루듯, 매일의 시도가 쌓여 나의 경험을 만듭니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

로컬 서버로 확인하려면 Node.js 환경에서 `node server.mjs` 실행 후 http://127.0.0.1:4173 에 접속하세요.

## 구성

- 물속 표지: 워터글래스 제목, 작업물을 담은 물방울, 일시정지 기능
- 꾸준한 실험: 매일 콘텐츠 제작과 개별 영상 조회수 사례
- 소개: 자기소개, 활동, 도구
- 활동 기록: 임시 작업 이미지와 소개
- 앱 프로젝트: 상세 대화상자와 기획 과정
- 웹 디자인: 비포·애프터와 개선 방향
- 연락: 실제 이메일 등록 전에는 준비 중 안내 표시

## 실제 정보로 교체할 부분

- `index.html`: YOUR NAME, 프로필, 활동, 사용 도구, 프로젝트 메타데이터
- `app.js`: `profile.email`, 프로젝트별 상세 설명 (`stories`)
- `assets/`: 실제 프로젝트 화면과 프로필 사진

앱과 웹 프로젝트는 구조를 보여주는 **가상 예시**이며, 실제 제작 이력이나 검증된 성과를 의미하지 않습니다. 첫 주 약 1천 회와 3주 차 53만 회는 사용자가 제공한 개별 영상 조회수이며, 전체 평균이나 동일 영상의 시계열 수치가 아닙니다. 실제 변경 사례, 집계 날짜, 플랫폼과 증빙 이미지는 보완 예정입니다.

## 접근성

본문 16px, 주요 조작 영역 48px 이상, 키보드 접근과 포커스 표시, 본문 바로가기, 모달 닫기 및 포커스 복귀를 제공합니다. 물방울은 마우스·키보드 선택 시 멈추며 전체 일시정지 버튼과 시스템 움직임 줄이기 설정을 지원합니다. 최종 이미지와 문구를 교체한 후 대비와 읽기 순서를 다시 점검하세요.

## 이미지와 글꼴

`assets/underwater.png`는 이 프로젝트를 위해 AI로 생성한 배경입니다. 프롬프트: ‘수면 아래 시점, 밝은 물빛, 잔잔한 수면과 굴절된 햇빛, 중앙에 여백, 텍스트·물방울·UI 없음’. 다른 SVG는 임시 프로젝트 화면을 표현한 자체 제작 이미지입니다. 외부 폰트는 Google Fonts의 Fredoka와 jsDelivr의 Pretendard를 사용하며, 연결되지 않아도 시스템 글꼴로 표시됩니다.

## GitHub Pages

저장소 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로 설정하면 정적 사이트로 게시할 수 있습니다. 실제 게시 여부는 GitHub 설정에 따라 결정됩니다.

## V02 디자인
전체 섹션을 하나의 물속 배경으로 연결하고, 아래로 갈수록 물빛이 깊어지도록 조정했습니다. 웹 1920×1080, 모바일 390px 기준으로 확인합니다. 캡처용 주소에 ?capture=1을 붙이면 물방울이 정지하고 이미지가 미리 로드됩니다. 캡처는 정지 이미지이며 실제 사이트의 움직임은 일반 주소에서 확인합니다. ocean-depth.png는 AI로 생성한 수중 배경 텍스처입니다.


## V03 수중 인터랙션

- 표지의 워터글래스 글자는 참고 시안의 재질을 따라 AI로 생성한 투명 이미지 레이어입니다. 메뉴·본문·버튼은 실제 HTML입니다.
- 표지 스크롤에 따라 장면과 제목이 확대되고, 다량의 기포가 올라오며 다음 섹션으로 이어집니다.
- 데스크톱 활동 기록은 화면을 고정한 채 스크롤로 오른쪽의 작업을 탐색하는 가로 갤러리입니다. 모바일은 세로로 읽습니다.
- 작업물 물방울을 누르면 팝·잔기포 효과 후 상세 대화상자가 열립니다.
- 움직임 줄이기 설정과 일시정지를 존중합니다. 캡처 모드는 전환을 펼친 전체 구성 기록용이며 실제 움직임은 일반 주소에서 확인합니다.
- 사용자 수정에 따라 조회수 사례를 첫 주 약 1천 회 내외 → 3주 차 53만 회로 변경했습니다. 전체 영상 평균이나 동일 영상의 시계열 수치로 해석하지 않습니다.
- 새 AI 이미지: water-reference.png(참고 이미지의 물빛·수면·굴절광, 텍스트·UI·큰 물방울 제외), waterglass-title.png(참고 이미지의 PORTFOLIO 글자만 투명 배경으로 분리·재현).

## V04 개선
- 디자이너 박세진으로 표기했습니다.
- 얇은 공기방울 이미지와 내부 굴절, 600개 전환 기포, 움직이는 굴절광을 추가했습니다.
- 표지 위쪽 휠로 프로젝트를 드러내며, 관찰 후 확대와 기포 전환이 진행됩니다.
- 버튼·메뉴 호버와 물방울 긴장·터짐, 8px 간격 체계를 적용했습니다. 상세 규칙은 DESIGN_RULES.md에 있습니다.
- 섹션별 PNG와 전체 구성 이미지는 design-exports/v04로 별도 제공됩니다. 긴 전체 이미지는 개요 확인용입니다.
